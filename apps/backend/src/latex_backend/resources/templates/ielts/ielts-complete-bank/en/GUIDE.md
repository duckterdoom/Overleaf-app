# IELTS Writing practice project guide

Original practice questions, not official exam papers or copies of IELTS CITY content. Places and data are fictional. Prompts remain in English in both project languages.

1. Compile `main.tex` for the collection. Each `question-taskN-*.tex` is a standalone question paper.
2. In IELTS Writing → Assign IELTS, choose a question file for each task and capture it. Set the matching profile and Academic/General Training variant; do not assign `answers.tex` as the question.
3. A two-task mock uses 60 minutes: approximately 20 minutes/150 words for Task 1 and 40 minutes/250 words for Task 2. Set the actual duration and deadline in the assignment form. Templates do not start timers.
4. Students write and submit in IELTS Writing. `answers.tex` is an optional LaTeX answer skeleton; it does not submit or start a timer.
5. Edit visual data in `questions/*.tex`, then update the matching CSV if present. CSV files are reference copies, not live chart inputs. Recompile and recapture before assigning.
6. Use the module checklist for feedback; ticks do not automatically produce a band. No fabricated model answers or bands are included. Share the project with the Student role and appropriate permission.
